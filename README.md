# 设计实践手册

围绕真实任务组织的中文原创设计知识库，面向软件、工作台、AI 产品与学习体验。主书解释机制、步骤、取舍与验证；轻量 Skill 帮助设计助手选择适合当前任务的内容。

> **当前状态：九篇专题的预览稿。** 当前包括二十七张原创SVG示意图。前八篇采用 Refactoring UI 前八个主题组的49个整理页、278次图片引用观察，以及明确列出的官方技术资料；第九篇另含本地PDF附件阅读启发及六项公开来源的限定文字核验。图片次数不是独立素材数，两类来源不合并为课程完成度。其余资料区的媒体补读和整本主书仍在推进；本版本不代表19个资料区全部完成，也没有真人使用或学习效果结果。

## 从任务开始

| 你要做什么 | 先解决的问题 | 应得到的结果 |
|---|---|---|
| 设计一个软件功能 | 谁在什么情境完成什么任务；过程如何成功、失败与恢复 | 一条可试的核心流程与明确状态 |
| 搭建工作台 | 如何同时知道整体方向、开始当前任务并保留结果 | 能操作、可继续、低维护的工作区 |
| 设计学习活动 | 学习者要独立做到什么；提示怎样帮助而不代替思考 | 首答、反馈、重试与迁移表现的证据 |

本手册按任务重组设计方法，不要求读者顺读所有来源，也不要求先学完整套工具、统计或求职课程。已有设计基线应成为改进起点；局部问题先作局部判断。

第一次使用时，挑一个真实任务和一个代表页面即可：还不知道先做什么，读第一篇；内容都在抢注意，读第二篇；内容归属、密度或窄屏有问题，读第三篇；连续阅读、混排或列表对齐有问题，读第四篇；颜色角色、状态辨认或主题配对有问题，读第五篇；临时层、阴影或重叠关系有问题，读第六篇；图片用途、叠字或裁切有问题，读第七篇；空状态、装饰含义或控件精修有问题，读第八篇；指标口径、实验推理或学习效果判断有问题，读第九篇。按对应章节改一个明确问题，再分别检查真实内容、操作与结果。把决定和观察留在已有项目记录里，不必另建日常台账。

## 本项目包含什么

计划写作任务、内容与信息架构、交互状态、可读排版、视觉层级、AI 控制、学习体验、原型验证、平台适配和发布沟通。每章都应有原创图示、完整例子、反例、执行步骤与验证边界。

公开内容以原创解释和图示为主体，也可包含按[引用规则](PROVENANCE.md#短引文与直接采用)标注的必要短引文。未经许可的长文、整页截图、课程附件与原始媒体不随本项目发布；个人分析、私人会话、访问凭据与带签名的下载地址不进入公开目录。

来源中的平台参数、产品能力与商业案例可能有版本或解释差异。实施时应按具体平台核验；示范案例不冒充真实用户研究，使用更顺畅也不等于学习者已经学会。

## Skill 状态

Skill 当前是可检查的路由草稿，附带两份必要参考。它没有安装到全局环境，也不会自行安装其他技能、改变项目架构或发布内容。它与主书共用任务结构，但不能把尚未完成的章节当作已经读取的依据。

需要复用时，可将 `skills/design-practice/` 作为完整目录交给支持该格式的工具。是否安装、如何发现以及实际行为验证取决于使用环境，本项目当前没有宣称完成这些步骤。
