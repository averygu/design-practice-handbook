## 什么算本项目原创图示

从要解释的问题出发，自行选择场景、文案、元素、关系和构图。图注写明“原创示意”以及其解释的机制；依据某项来源原则时仍保留思想来源。

仅改变现有图的颜色、尺寸、语言、排版或描摹轮廓，不视为已经完成独立原创。本版另含用户已确认授权范围内的课程图片，记录见[课程图片登记](../course-images-sources.md)；其他来源图片不因此获得相同授权。

## 选择形式

- Mermaid：状态、分支、职责、数据流和关系。
- SVG：布局、分组、排版、语义色、图标情境和控制变量对照。
- 需要播放或交互才能解释的机制：提供清楚的文字与静态结构图，并明确静态图不能证明运动手感或实际设备行为。

每张图应有标题、替代说明、图例和正文解释，中文在实际显示尺寸可读。状态区分同时使用文字或形状，不只依赖颜色。前后对照尽量保持其余变量一致；示意数据明确标注，不能伪造增长与研究结果。

## 每张成品图的记录

新增图时在邻近的图示登记中写明：稳定ID、文件、章节、原创者或创作方式、日期、解释任务、相关来源ID、第三方元素（没有则写无）、许可状态、文字替代及实际渲染检查范围。

SVG或Mermaid源文件与导出图保持同步。不嵌入外部字体、远程图片、跟踪请求、脚本或未登记的品牌资产。说明图不应依赖网络才能显示。

## 拟制作的图组

| 图组 | 主要解释 |
|---|---|
| 任务与证据 | 任务入口、目标/步骤/情境、原话到决定的证据链 |
| 内容与表达 | 信息架构三模型、关键词探索、动作与结果文案 |
| 流程与视觉 | 状态转换、保存与采用、五类间距、窄屏结构、中文混排、语义色 |
| 交互与复用 | 图标情境、可打断反馈、代表页与组件状态 |
| AI与学习 | 上下文边界、人机职责、原文与版本、学习证据、逐步撤去提示 |
| 验证与交付 | 不同证据的结论范围、平台适配、本地与服务依赖、诚实案例叙事 |

## 复用

本项目原创图示的复用许可尚待项目统一明确，见[许可状态](../../NOTICES.md)。以后获许可复用时，应保留必要归属、图注中的条件和示意属性，不把图改称真实产品截图或已验证研究结果。第三方素材如获许可例外使用，单独注明其权利与要求。
